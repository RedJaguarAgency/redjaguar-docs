**News Schema → Publisher** holds the information that identifies your newsroom in the news sitemap and in the structured data of every page.

| Field | What to write |
|---|---|
| **Publication name** | Must match exactly the name shown for your publication on Google News. Leave it empty to use the site title. |
| **Logo** | Click **Choose image**. If you leave it empty, the plugin uses the logo of your theme (**Appearance → Customize → Site Identity**). If the logo is too small, the screen asks for a larger one. |
| **Founding date** | A year (`1996`) or a full date (`1996-05-01`). |
| **City** and **Country** | The country as a two-letter ISO code (`MX`, `CO`, `US`). |
| **Newsroom email** | A public contact address. It is published in the structured data. |
| **Official profiles** | One address per line: social networks, Wikipedia, Wikidata. |

:::note[Your safety first]
City and country are enough. You do not need to publish a street address if it is not safe to do so.
:::

## Import from Yoast SEO or Rank Math

If one of those plugins already has some of these details, the screen offers **Import from …**. It fills only the empty fields and changes nothing in the other plugin. Review the imported fields before saving.
