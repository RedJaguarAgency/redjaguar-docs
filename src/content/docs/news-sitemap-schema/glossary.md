title: Glossary
description: The words the plugin and this manual use.

---

**Alternative text**
: A short description of an image for people who use screen readers. It also helps search engines understand the image.

**Author page**
: The page of your site that lists the articles of one author. Its address usually ends in `/author/` and a name.

**Byline**
: The name that signs an article. It can be a person, a pseudonym or the newsroom.

**Cache**
: Saved copies of your pages that make the site faster. If it is not cleared, readers and search engines can see an old version.

**Canonical address**
: The main address of a page that can be reached in several ways. Search engines show that one and ignore the copies.

**Crawling and indexing**
: Crawling is when a search engine visits your pages; indexing is when it keeps them so they can appear in results. A page can be crawled and not indexed.

**E-E-A-T**
: Experience, expertise, authoritativeness and trust: what Google's reviewers look for in a source. Author biographies and editorial policies are how a site shows them.

**Editorial policies**
: Public pages that explain how the newsroom works: corrections, ethics, ownership and funding, and others.

**Featured image**
: The main image of an article. Google recommends it at least 1,200 pixels wide, with versions cut to 16:9, 4:3 and 1:1.

**Google Discover**
: The feed of articles Google suggests on phones, without a search. It favors large, good-quality images.

**Google News**
: Google's news service, at news.google.com and in its app. There is no form to join: Google chooses the sites by itself.

**Google Search Console**
: Google's free tool for site owners: it shows which pages Google sees, the errors it finds, and where you submit your sitemaps.

**JSON-LD**
: The format in which the structured data is written inside the page, in a script block that readers do not see.

**Login name**
: The user name used to sign in to WordPress. If it is public, an attacker only needs to guess the password.

**News sitemap**
: A special sitemap with only the articles of the last 48 hours, their title, date and language.

**NewsArticle**
: The schema.org type of a news article. It carries the headline, dates, images and authors.

**NewsMediaOrganization**
: The schema.org type of a newsroom. It carries the name, logo, location and the addresses of your editorial policies.

**noindex**
: A tag that asks search engines not to show a page in results. Useful on test copies; a problem on articles.

**Paywall and cloaking**
: A paywall hides articles from readers who do not pay. If the text is still in the page, Google may see it as cloaking, showing it one thing and readers another, unless the structured data says which part is not free.

**Photo metadata (EXIF)**
: Data that cameras and phones write inside each photo: date, device, its serial number and often the GPS location of where it was taken.

**REST API**
: The way WordPress shares its content with apps and other sites. By default it publishes a list of the users who have written articles.

**robots.txt**
: A small file at the root of your site that tells search engines which parts they may not visit. A wrong line can hide the whole site.

**schema.org**
: The shared vocabulary for structured data, used by Google, Bing and others.

**Site Health**
: The WordPress screen, in Tools, that reviews the state of the site. The plugin adds its results there.

**Sitemap**
: A file that lists the addresses of a site so search engines find them. WordPress makes a general one by itself.

**Structured data**
: Information inside the page, invisible to readers, that describes it to machines: type of content, author, dates, publisher.

**Test copy (staging)**
: A copy of the site to try changes before they reach the real one. It should be hidden from search engines.

**Top stories**
: The block of news at the top of Google search results. Any site can appear there, not only those in Google News.
