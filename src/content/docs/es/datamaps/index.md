**Red Jaguar - DataMaps** convierte un sitio de WordPress en un monitor de datos: una base de datos con tus propios campos, que mantiene tu equipo, publicada como un mapa interactivo con cifras, gráficos, filtros y tablas que se actualizan solos.

Está hecho para redacciones y organizaciones que documentan lo que las cifras oficiales dejan fuera (violencias, agresiones a la prensa, conflictos ambientales, cortes de internet), y sirve para cualquier dato con un lugar y una fecha.

En el menú de WordPress aparece como **Red Jaguar DataMaps**.

## Qué hace

- **[Bases de datos](/es/datamaps/datasets/) con tus propios [campos](/es/datamaps/fields/)**, desde cero o desde una plantilla.
- **Llénalas** a mano, [importando una planilla](/es/datamaps/import/), [sincronizando una hoja de Google](/es/datamaps/google-sheets/) o con [formularios públicos](/es/datamaps/forms/).
- **Revísalas:** [calidad de los datos](/es/datamaps/quality/), verificación, notas privadas y el historial de cada cambio.
- **Publícalas** como [vistas](/es/datamaps/views/): portada, mapa, cifras, gráficos, filtros, línea de tiempo, fichas y tabla, en cualquier página o [en otro sitio](/es/datamaps/place-views/#mostrar-en-otro-sitio).

## Primero la privacidad

Todo campo empieza privado. Las coordenadas exactas nunca se publican, los lugares pequeños se protegen y los valores privados se pueden cifrar. Mira [Privacidad y seguridad](/es/datamaps/privacy-and-security/).

## Requisitos

- WordPress 6.5 o posterior y PHP 7.4 o posterior, con las extensiones `sodium` y `zip` (las tiene casi cualquier hosting).
- Una [licencia](/es/licenses/) activada para el dominio del sitio.
