Mientras la licencia esté activa, las versiones nuevas aparecen en **Escritorio → Actualizaciones** y en **Plugins**, como cualquier otro plugin. Actualízalos ahí.

También puedes descargar la última versión desde [tu cuenta](https://redjaguar.agency/plugins/account/) e instalarla con **Plugins → Añadir nuevo plugin → Subir plugin → Reemplazar la actual con la subida**.

## Ver la versión

La pantalla de Licencia del plugin muestra la versión instalada y, si hay una más nueva, "(la versión … está disponible en Actualizaciones)". Para buscar una versión nueva en ese momento, haz clic en **Revisar ahora**.

## Actualizaciones firmadas

Red Jaguar firma cada actualización. Antes de instalarla, el plugin revisa la firma. Si no coincide, la actualización se rechaza y no se instala nada:

- "Se rechazó la actualización: no viene de la tienda."
- "Se rechazó la actualización: su firma no coincide."

Si ves uno de estos mensajes, no instales el plugin desde otra fuente. Avísanos a [roar@redjaguar.agency](mailto:roar@redjaguar.agency).

## "Renueva la licencia para recibir esta actualización"

La licencia venció. El plugin sigue funcionando con la versión que tienes. Renuévala desde tu cuenta para recibir la versión nueva.
