New images are cleaned on upload. Images uploaded before the plugin was active, or added another way (FTP, a migration, an import), need a review.

## Review

In **Red Jaguar Newsroom → Overview**, click **Review the media library**. It reads every image: the published copy, the original, each size and the backups WordPress keeps when an image is edited. **It changes nothing.**

Then it shows, in plain language, what it found: images that reveal where they were taken, serial numbers, owners' names, hidden thumbnails, kept originals. Click **See which ones** to list them in the media library.

Review again after images are added another way: **Review again**.

## Clean

**Clean these images** removes the hidden data from every file of those images, and from their record in WordPress. The pictures keep their quality and their addresses.

## Delete the originals

**Delete the originals** deletes the full-size originals of the images already uploaded, and shows how much space it frees. Check **I understand that deleted originals cannot be recovered** to confirm.

## In the background

On large libraries, any of these tasks can run **in the background** with WordPress's scheduled tasks. You can close the screen and come back later to see how it is going, or **Stop** it.

If it does not move for more than ten minutes, the overview tells you why. WordPress runs scheduled tasks when someone visits the site, so on a site with few visits it can be slow.

## The Privacy column

The media library has a **Privacy** column that shows what each image still carries, or **Clean**, or **Not reviewed**.

## Alternative text

The overview also counts the images without alternative text and lists them. It is not hidden data, but it matters for people who use screen readers and for image search.
