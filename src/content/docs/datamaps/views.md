Each view is a piece you place in a page. Views of the same dataset on one page share their filters: choosing a year in the filters changes the map, the figures and the table at once.

In the **Views** tab, click **New view** and choose its type.

## Types of view

| View | What it shows |
|---|---|
| **Cover** | Headline, text, map and figures in one block, for the top of a page. |
| **Map** | Circles per region, colored regions or one point per record. |
| **Figures** | Big numbers: totals, a year, change from the previous year. |
| **Chart** | Bars, line, donut, 100 % bars, calendar, histogram, squares or pyramid. |
| **Filters** | Year, region and list fields. They filter every view of the page. |
| **Timeline** | Records per year or month. |
| **Cards** | One card per record, like a memorial, with the full record. |
| **Table** | A searchable, sortable list of records. |

Views only show **published records** and **public fields**. If a view says there are no public fields of a suitable type, make fields public in the [Fields](/datamaps/fields/) tab.

## Common options

- **Name in the dashboard** and **Title on the page (optional).**
- **Style:** the site style or custom colors. See [Style](/datamaps/style/).
- **Footer:** shows "Data updated on…", the source and the methodology link, from the Settings of the dataset.
- **Preview changes** shows the view as visitors see it, with published records only. Nothing changes on the site until you click **Save view**.

## Map

- **Mode:** circles per region (size = number of records), colored regions (intensity = number of records), or one point per record (grouped when zoomed out).
- **Level:** department or municipality.
- **Base map:** none (only the regions, no requests to other servers) or OpenStreetMap streets (visitors connect to tile.openstreetmap.org).
- Legend, zoom, region names, a panel with the figures of each region when clicked, and more in **Options** and **Details**.
- The map popup shows the public fields marked **Map popup**.

Points mode never uses exact coordinates. See [Privacy and security](/datamaps/privacy-and-security/).

## Figures

Each figure can be the total of records, the records in a year, the change from the previous year, regions with records, records with a value, a percentage, the average of a number or the most common value of a field. Labels are automatic if you leave them empty.

The change compares the current year with the same period of the previous year, up to the date of the latest record, and says so.

## Charts

| Kind | For |
|---|---|
| Bars | Records per value of a list field. |
| Donut | Parts of the whole, up to 5 (the rest go to "Others"). |
| 100 % bars | The parts in each region or year. |
| Line | Records over time, up to 4 lines. |
| Calendar | Records per month, one row per year. |
| Histogram | How a number is spread: ages, amounts. |
| Squares | One value out of 100 ("1 in 3"). |
| Pyramid | Two age groups face to face. |

Clicking a bar or a part of a donut filters every view on the page. Palettes are safe for people with color blindness.

## Filters

Buttons or drop-down lists for year, region and the public list fields you choose. With **Share** on, the filters are kept in the page address, with a button to copy the link.

## Cover

Kicker, headline, text, a button, the map and figures. Use **Heading level 1** when the cover is the main title of the page, as on a home page.

## Visitors can

- download a map as an image (**Download image**);
- download the public data as CSV, if **Open data** is on in Settings.
