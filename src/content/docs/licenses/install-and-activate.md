You need an administrator account on the WordPress site.

## 1. Download the plugin

1. Log in to your account at [redjaguar.agency/plugins/account](https://redjaguar.agency/plugins/account/).
2. In the license you want to use, click **Download the latest version**. You get a `.zip` file. Do not unzip it.

## 2. Install it

1. In WordPress, go to **Plugins → Add New Plugin → Upload Plugin**.
2. Choose the zip and click **Install Now**.
3. Click **Activate**.

If you are replacing an older copy of the same plugin, WordPress asks what to do: choose **Replace current with uploaded**. Your settings are kept.

## 3. Activate the license

1. Open the License screen of the plugin:

   | Plugin | Where |
   |---|---|
   | News Sitemap & Schema | **News Schema → License** |
   | DataMaps | **DataMaps → DataMaps license** |

   Until you activate it, the plugin menu shows only this screen.
2. Paste the **License key** from the email.
3. Click **Activate on this site**.

The screen now shows the state of the license, the date until which you get updates, and the version installed. The plugin is ready.

## If something goes wrong

- **"This license is in use on another site."** Each license works on one domain. Release it from the other site, or from your account, and try again. See [Move a license to another site](/licenses/move-to-another-site/).
- **"The store could not be reached."** Your server could not connect to redjaguar.agency. Try again in a few minutes. If it keeps happening, ask your hosting provider whether the server can make outgoing connections.
- **Lost the key?** Your account can make a new one. See [Your account](/licenses/account/).
