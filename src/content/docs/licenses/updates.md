While the license is active, new versions appear in **Dashboard → Updates** and in **Plugins**, like any other plugin. Update them there.

You can also download the latest version from [your account](https://redjaguar.agency/plugins/account/) and install it with **Plugins → Add New Plugin → Upload Plugin → Replace current with uploaded**.

## See the version

The License screen of the plugin shows the version installed and, if there is a newer one, "(version … is available in Updates)". To look for a new version right away, click **Check now**.

## Signed updates

Every update is signed by Red Jaguar. Before installing it, the plugin checks the signature. If it does not match, the update is refused and nothing is installed:

- "The update was refused: it does not come from the store."
- "The update was refused: its signature does not match."

If you see one of these messages, do not install the plugin from another source. Tell us at [roar@redjaguar.agency](mailto:roar@redjaguar.agency).

## "Renew the license to get this update"

The license expired. The plugin keeps working with the version you have. Renew it from your account to get the new version.
